# Sprint_5 - Автотесты для Stellar Burgers

# Описание проекта
Проект содержит автоматизированные тесты для сервиса Stellar Burgers (https://stellarburgers.education-services.ru/) — космического фастфуда, где можно собирать и заказывать бургеры из необычных ингредиентов.

# Покрытие тестами
- Регистрация пользователя (успешная и с недопустимым паролем)
- Вход и выход через разные методы
- Навигация по личному кабинету 
- Навигация по разделам конструктора

# Установка и запуск
1. Установите зависимости: `pip install selenium pytest`
2. Запустите тесты: `pytest tests/`
